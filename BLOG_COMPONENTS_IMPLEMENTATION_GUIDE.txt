═══════════════════════════════════════════════════════════════════════════════
DATABASE INTEGRATION
═══════════════════════════════════════════════════════════════════════════════

When user clicks "Publish" in editor:

1. Collects all form data:
   {
     title: string,
     subtitle: string,
     excerpt: string,        // Plain text only
     content: string,        // HTML from Quill ✓
     category: string,
     tags: string[],
     imageUrl: string,
     authorName: string,
     authorRole: string,
     isPublished: boolean
   }

2. Validates all required fields

3. Sanitizes HTML content (removes scripts, malicious code)

4. Calculates metadata:
   - read_time: word count / 200
   - slug: generated from title
   - excerpt: auto-generated if not provided

5. Sends POST request to /api/blog/create
   {
     method: 'POST',
     headers: { 'Content-Type': 'application/json' },
     body: JSON.stringify(formData)
   }

6. Database saves:
   INSERT INTO blog_posts (
     title, content, excerpt, category, tags,
     author_name, is_published, created_at
   ) VALUES (...)

When user visits blog detail page:

1. BlogDisplay component fetches from /api/blog/[slug]

2. API retrieves post data from database

3. Component renders HTML content with dangerouslySetInnerHTML:
   <Box dangerouslySetInnerHTML={{ __html: post.content }} />

4. Browser applies CSS styling and displays formatted content
